# 🚀 CareerPilot-AI

An AI-powered career assistance application designed to help users explore career opportunities and prepare for their professional journey.

## 🌐 Live Demo

**Try CareerPilot-AI here:**  
👉 https://careerpilot-ai-y17z.onrender.com

## ✨ Features

- 🤖 AI-powered career assistance
- 💼 Career guidance and support
- 🔐 User registration and login
- 📄 Career-related tools and resources

*Features depend on the functionality implemented in the application.*

## 🛠️ Technologies Used

- **Backend:** Python, Flask
- **Database:** SQLite / SQLAlchemy
- **Frontend:** HTML, CSS, JavaScript
- **AI Integration:** Google Gemini API
- **Deployment:** Render
- **Version Control:** Git and GitHub

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Anukarsh123/CareerPilot-AI.git
   ```

2. Open the project folder:

   ```bash
   cd CareerPilot-AI
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure the required environment variables using a local `.env` file. Refer to `.env.example` for the variable names. Never commit API keys or other secrets.

5. Start the application:

   ```bash
   python app.py
   ```
